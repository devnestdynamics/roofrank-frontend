What's new in this version:
  • One unified SVG primitive — same viewBox (0 0 40 40), same path coordinates, same proportions. Whether it's the brand mark in the app bar, the brand mark inside the Brief eyebrow, or the score viz on a deal card, it's literally the same component with different classes.
  • Roof always sage. The roof never changes color — it's the constant brand element. Only floors carry the score.
  • Floors light up bottom-up by count. Strong Buy lights all 3 in forest. Buy lights bottom 2 in forest-3. Watch lights bottom 1 in amber. Pass lights bottom 1 in rose. The remaining floors stay dim (cream-3 ghost color) so the silhouette is always recognizable as a building.
  • The number above the mark shares the tier color, so the two read as one unit at a glance.
  • Two distinct visual roles for the same shape: sage-on-forest in the app bar means "this is Deckers" (the identity). Tier-colored floors on a deal card means "this deal scored X" (the verdict). Brand and score are the same primitive doing different jobs.
